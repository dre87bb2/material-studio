# Material Studio for IngeTrazo

![GitHub Downloads](https://img.shields.io/github/downloads/dre87bb2/material-studio/total.svg?style=flat-square&color=brightgreen)

Material Studio is a per-material PBR editor and Blender rendering companion for IngeTrazo.

Features include material properties and texture maps, image-based and procedural surface relief,
emission and Glow/Bloom controls, lighting, camera depth of field, and render style presets.
Extension-specific material and camera settings are stored in the `.igz` project.

## Install

Install from **Extensions → Extension Manager** in IngeTrazo, or copy the `material_studio`
package folder from the release ZIP into the user plugins folder.

## Requirements

- IngeTrazo 0.6.x (catalogue entry currently lists 0.6.2.1 as the tested version)
- Blender 5.3 recommended for the current render path; legacy Blender 4.x compositor fallback retained.
